# Agent rules

Read, in this order, before planning or editing:
1. `AGENTS.md` (framework guidelines)
2. `.ai/rules/index.md` and every rule file it maps to your paths (always `.ai/rules/project.md`)
3. `.github/copilot-instructions.md` (architecture, tenant and API invariants, build and test commands)

This project is PHP 8.5 / Laravel 13 / Pest / PostgreSQL. It is not .NET: ignore any C#, MediatR or EF Core advice.
